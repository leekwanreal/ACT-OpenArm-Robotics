How it runs

Start runs the model continuously, as infer_robot.py: every step takes the first action of the chunks, the newest weighing most, and the arrows follow the newest chunk. Nothing moves until Execute; it ends by itself back home (or after time seconds; 0 for no limit) and eases the arm to zero. Generate trajectory infers once and Run trajectory plays those 50 steps once; Reset to zero eases the arm to zero, grippers open. Stop holds the arm where it is. The list swaps the model while nothing runs; Load… brings a new one: an .onnx is kept under checkpoint/onnx/, a .pth under checkpoint/pth/ and exported to .onnx first.

How it runs

SmolVLA runs on a GPU machine (openarm_smolvla's scripts/serve.py); openarm_smolvla asks it for a chunk every half second. Start runs it continuously while nothing moves, the arrows following the newest chunk; Execute lets it drive until it is back home, time runs out, or Stop. Generate trajectory asks once and Run trajectory plays those 50 steps once. There is no prompt: the model is trained on one task (Task), which the server gives it.
