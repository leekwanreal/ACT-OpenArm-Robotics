# OpenArm v1 browser assets

These files are the visual-only subset of
[`enactic/openarm_description`](https://github.com/enactic/openarm_description)
at commit `14ff67b638ff1c738a1b9a6be8aaa5ce5ed2c831`.

Included:

- generated OpenArm v1 URDF;
- body and arm visual Collada meshes;
- parallel-gripper finger visual mesh.

Collision meshes and ROS-only configuration are intentionally omitted from the
web bundle. The upstream Apache-2.0 license is preserved in
`OPENARM_DESCRIPTION_LICENSE`.
